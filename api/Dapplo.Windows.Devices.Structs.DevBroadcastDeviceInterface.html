DeviceSetupClassGuid

Returns the Device Setup Class GUID from the Windows registry. This is the Class GUID shown in Device Manager (e.g., {4d36e968-e325-11ce-bfc1-08002be10318} for Display adapters). This is different from DeviceClassGuid which is the Device Interface Class GUID from the notification message. Returns null if the registry key cannot be accessed or the ClassGUID value is not found.
