Interface IWICBitmapSource

Namespace
Dapplo.Windows.Imaging.Interop
Assembly
Dapplo.Windows.Imaging.dll

A source of pixels for WIC. It is called on WIC objects (decoded frames, format converters) and implemented by Dapplo.Windows.Imaging to hand pixels from memory or from a row callback to an encoder without a copy, so it is public and COM visible. See IWICBitmapSource interface
