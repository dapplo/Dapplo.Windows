AdjustWindowRect(NativeRect, WindowStyleFlags, bool, ExtendedWindowStyleFlags, uint?)

Calculates the required size of the window rectangle, based on the desired size of the client rectangle and the provided DPI. This is a convenient wrapper around the AdjustWindowRectExForDpi Win32 API.

public static NativeRect? AdjustWindowRect(NativeRect clientRect, WindowStyleFlags style, bool hasMenu = false, ExtendedWindowStyleFlags exStyle = ExtendedWindowStyleFlags.WS_EX_LEFT, uint? dpi = null)

Parameters

clientRect NativeRect

The desired client rectangle.

style WindowStyleFlags

The window style of the window.

hasMenu bool

Indicates whether the window has a menu.

exStyle ExtendedWindowStyleFlags

The extended window style of the window.

dpi uint?

The DPI to use for scaling. If not provided, uses the system DPI.

Returns

NativeRect?

The calculated window rectangle, or null if the function fails.
