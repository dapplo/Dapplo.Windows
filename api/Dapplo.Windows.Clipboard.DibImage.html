DefaultMaxPixelCount

The default maximum number of pixels (width * |height|) which TryDecode(byte[], out DibImage) and TryGetAsDib(IClipboardDataSource, out DibImage) decode: 64 megapixels (e.g. 8192 x 8192), which are 256 MiB of BGRA32 pixels. Larger bitmaps return false; pass a larger maximum when you really need them.

public const long DefaultMaxPixelCount = 67108864

TryDecode(byte[], out DibImage)

Decode a device independent bitmap: BITMAPINFOHEADER, BITMAPV4HEADER or BITMAPV5HEADER followed by the optional masks or palette and the pixels, or a BITMAPCOREHEADER with an RGBTRIPLE palette. Supported: BI_RGB with 1, 4, 8 (palette), 16, 24 and 32 bpp; BI_BITFIELDS / BI_ALPHABITFIELDS with 16 and 32 bpp; bottom-up and top-down. Compressed bitmaps (RLE, JPEG, PNG) return false. Bitmaps with more than DefaultMaxPixelCount pixels return false, see TryDecode(byte[], long, out DibImage).

public static bool TryDecode(byte[] dib, out DibImage image)

Remarks

32 bpp BI_RGB officially has no alpha channel; it's used when at least one pixel has a non-zero value there, otherwise the image is opaque. Masks which follow a BITMAPV4HEADER / BITMAPV5HEADER although they are already in the header (some writers do this, Greenshot even with reversed bytes) are detected and skipped.

TryDecode(byte[], long, out DibImage)

Decode a device independent bitmap like TryDecode(byte[], out DibImage), with a maximum size. The size is checked from the header before anything is allocated, so a crafted header can't make the decoder allocate huge amounts of memory: bitmaps with more than maxPixelCount pixels (width * |height|), or with more pixels than fit in one byte array, return false.

TryDecode(ReadOnlySpan<byte>, long, Span<byte>, int)

Decode a device independent bitmap into memory of the caller (e.g. the locked bits of a 32 bpp bitmap), without allocating the pixels: top-down rows of B, G, R, A bytes with straight alpha (A = 255 when the image has no alpha), exactly the pixels TryDecode(byte[], long, out DibImage) puts in Pixels. Use TryReadInfo(ReadOnlySpan<byte>, long, out int, out int, out bool) first for the size. Bytes after width * 4 in each row (the padding of a larger stride) are not written.

TryReadInfo(ReadOnlySpan<byte>, long, out int, out int, out bool)

Read the size of a device independent bitmap and whether it has alpha, without decoding (or allocating) the pixels, e.g. to choose the pixel format of the memory for TryDecode(ReadOnlySpan<byte>, long, Span<byte>, int). The header is validated exactly like TryDecode(byte[], long, out DibImage) does, and hasAlpha is what HasAlpha of the decoded image would be (for 32 bpp this reads the alpha values of the pixels).
