A listener for Windows session change events. Currently handles lock/unlock and logon/logoff events. Other session change events (console connect/disconnect, remote connect/disconnect, etc.) are not exposed but can be added in the future.

Events

RegistrationFailed

Event fired when registering for session notifications (WTSRegisterSessionNotification) finally failed. Registration can fail early at logon (RPC_S_INVALID_BINDING) when the Remote Desktop Services are not started yet, therefore a failed registration is retried every 2 seconds for about 2 minutes before this event is raised. The event is raised on the thread of the SharedMessageWindow, the exception is a Win32Exception.
