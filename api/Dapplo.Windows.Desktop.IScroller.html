Interface IScroller

Namespace
Dapplo.Windows.Desktop
Assembly
Dapplo.Windows.dll

Scrolls a window or an area inside a window step by step, e.g. for a scrolling capture. Implemented by WindowScroller (Win32 scroll bars, see GetWindowScroller(IInteropWindow, ScrollBarTypes, bool)) and by the UI Automation based scroller of the Dapplo.Windows.Automation package, so a caller can try one and fall back to the other with the same code.

StepFraction

The part of a page that Next() and Previous() scroll, greater than 0 and at most 1. The default 1.0 scrolls a full page; use e.g. 0.5 so consecutive frames overlap for stitching.

double StepFraction { get; set; }
