Remarks

Only formats which are stored in global memory (HGLOBAL) can be copied: handle formats (CF_BITMAP, CF_METAFILEPICT, CF_PALETTE, CF_ENHMETAFILE, the display and private formats and CF_GDIOBJ*) are skipped. Windows synthesizes CF_DIB / CF_DIBV5 from CF_BITMAP and CF_TEXT from CF_UNICODETEXT, those are copied. Reading a format makes the application which copied render it when it uses delayed rendering, so pass only the formats you need.
