DpiHandler(bool)

Create a DpiHandler. This does not change the DPI awareness context of the thread, the DPI awareness of a window is decided when it's created. Use the process DPI awareness (manifest or NativeDpiMethods.EnableDpiAware), or wrap the window creation with NativeDpiMethods.ScopedThreadDpiAwarenessContext (DpiAwareForm does this for you).

public DpiHandler(bool needsListenerWorkaround = false)

Parameters

needsListenerWorkaround bool

Properties

ApplySuggestedWindowRect

Specifies if the DpiHandler moves and resizes the window to the rectangle which Windows suggests with WM_DPICHANGED (default true). When true, the WM_DPICHANGED message is reported as handled. Set this to false when the UI framework applies the suggested rectangle itself, e.g. WinForms or WPF with Per-Monitor (v2) DPI support enabled.

public bool ApplySuggestedWindowRect { get; set; }

Property Value

bool

Dpi

Retrieve the current DPI for the UI element which is related to this DpiHandler. As long as the DPI is not known yet (see IsDpiKnown), this returns DefaultScreenDpi.

public int Dpi { get; }

Property Value

int

IsDpiKnown

True when the DPI of the UI element was determined (e.g. after WM_CREATE), before that Dpi returns the default of 96.

public bool IsDpiKnown { get; }

Property Value

bool

MessageHandler

The subscription which feeds the window messages to this DpiHandler, e.g. set by the AttachDpiHandler extensions in Dapplo.Windows.Forms or Dapplo.Windows.Wpf. It is disposed together with this DpiHandler.

public IDisposable MessageHandler { get; set; }

Property Value

IDisposable

OnDpiChanged

This publishes whenever the DPI changes, with some details. The first notification is published when the DPI is determined for the first time, the PreviousDpi is 0 in that case. The sequence completes when this DpiHandler is disposed, a recreate of the window handle does not complete it.

public IObservable<DpiChangeInfo> OnDpiChanged { get; }

Property Value

IObservable<DpiChangeInfo>
