Fields

DefaultInputDesktopAccess

The access rights which are requested by default for the input desktop: enough to switch a thread to it, create windows and read or write the objects on it. The journal and hook rights are not requested, as these are often denied for normal users or on the secure desktop.

public const DesktopAccessRight DefaultInputDesktopAccess = DESKTOP_READOBJECTS | DESKTOP_CREATEWINDOW | DESKTOP_CREATEMENU | DESKTOP_ENUMERATE | DESKTOP_WRITEOBJECTS
