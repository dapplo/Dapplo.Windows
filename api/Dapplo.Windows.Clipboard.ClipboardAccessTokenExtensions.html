GetBlockingProcessName(IClipboardAccessToken)

The application which kept the clipboard open when the token couldn't open it (IsOpenTimeout), to show to the user: the file name of its executable (e.g. "notepad.exe"), else the process name, else the title of BlockingWindow; null when unknown or when the clipboard was opened. This is the same value as BlockingProcessName.

public static string GetBlockingProcessName(this IClipboardAccessToken clipboardAccessToken)

Returns

Remarks

For the tokens of Access(nint, int, TimeSpan?, TimeSpan?) and AccessAsync(nint, int, TimeSpan?, TimeSpan?, CancellationToken) the name was determined when opening failed, so this doesn't query the process again. For other implementations of IClipboardAccessToken it's determined now from BlockingProcessId and BlockingWindow.
