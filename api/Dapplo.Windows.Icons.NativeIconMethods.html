DestroyIcon(nint)

Destroys an icon and frees any memory the icon occupied.

public static extern bool DestroyIcon(nint hIcon)

Parameters

hIcon nint

A handle to the icon to be destroyed. The icon must not be in use.

Returns

bool

bool true if the destroy succeeded

Remarks

It is only necessary to call DestroyIcon for icons and cursors created with the following functions: CreateIconFromResourceEx (if called without the LR_SHARED flag), CreateIconIndirect, and CopyIcon. Do not use this function to destroy a shared icon. A shared icon is valid as long as the module from which it was loaded remains in memory. The following functions obtain a shared icon.

LoadIconMetric(nint, nint, IconMetricSize, out nint)

Loads an icon with the specified dimensions from an icon resource. The icon resource can be from an application instance or loaded from a file. This function automatically scales down a larger image to the requested size. See LoadIconMetric function

public static extern int LoadIconMetric(nint hInstance, nint pszIconName, IconMetricSize lims, out nint hIcon)

Parameters

hInstance nint

A handle to the module of either a DLL or executable (.exe) that contains the icon to be loaded. To load a stock system icon, set this parameter to IntPtr.Zero.

pszIconName nint

The icon name. To load a stock system icon, use one of the IDI_* constants. To load from resources, use MAKEINTRESOURCE macro result or the string name.

lims IconMetricSize

The size of the icon to load. This can be SmallIcon (SM_CXSMICON) or StandardIcon (SM_CXICON).

hIcon nint

When this function returns, contains a handle to the loaded icon.

Returns

int

If the function succeeds, it returns S_OK (0). Otherwise, it returns an HRESULT error code.
