GetContainingIntegerBounds(out int, out int, out int, out int)

Calculate the smallest integer rectangle which contains this NativeRectFloat: left and top are floored, right and bottom are rounded up. The result is normalized (no negative width or height). This makes sure that Right does not drift, as it would when truncating left and width independently.
