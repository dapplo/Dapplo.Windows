HasOverlap(NativeRectFloat, NativeRectFloat)

Check that two rectangles overlap with each other, this means they share a non-empty area. Right and Bottom are exclusive, so adjacent rectangles (e.g. rect1.Right == rect2.Left) do not overlap, a rectangle which contains the other (or is contained) does overlap. This is the same as IntersectsWith(NativeRectFloat, NativeRectFloat).

[Pure]
public static bool HasOverlap(this NativeRectFloat rect1, NativeRectFloat rect2)

Parameters

rect1 NativeRectFloat

The first rectangle

rect2 NativeRectFloat

The second rectangle

Returns

bool

The rectangles overlap
