HasResolution

True when the file itself stores a resolution (PNG pHYs in pixels per meter, JFIF density in inch or cm, EXIF/TIFF XResolution with a unit, JPEG XR WIDTH_RESOLUTION, BMP pixels per meter, ...). False when DpiX / DpiY are only the default of the decoder, because the file stores none, or only an aspect ratio. WIC reports a resolution in both cases, e.g. 96 for a PNG without pHYs and 72 for a WebP without EXIF; use your own default when this is false.
