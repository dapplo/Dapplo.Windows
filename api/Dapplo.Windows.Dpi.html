BitmapScaleHandler

Factory for the generic BitmapScaleHandler

BitmapScaleHandler<TKey, TValue>

This provides bitmaps scaled according to the current DPI. If the DPI changes, it will reapply the bitmaps and dispose the old ones. The BitmapScaleHandler owns every value which the provider and the scaler return: they are cached per DPI, and disposed when the DPI changes or the handler is disposed. When the scaler returns a new instance, the one from the provider is disposed directly. So the provider must return a new instance for every call (not a shared one). Dispose the handler on the UI thread (e.g. when the form closes), it assigns the default value to all targets.
