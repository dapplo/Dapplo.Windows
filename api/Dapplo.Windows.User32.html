DisplayInfo

The DisplayInfo class is like the Screen class, only not cached.

ThreadDesktopScope

Switches the calling thread to the current input desktop, and restores the previous desktop of the thread when disposed. This must be created and disposed on the same thread. Note: SetThreadDesktop fails when the thread already owns a window or a hook, which is typical for a UI thread, so use a dedicated thread. Check IsSwitched to see if the switch worked.

User32Api

Native wrappers for the User32 DLL

WindowHandles

The special window handle values of the Windows API, e.g. for the hWndInsertAfter of SetWindowPos(nint, nint, int, int, int, int, WindowPos), the hWnd of PostMessage(nint, uint, nint, nint) or the parent of CreateWindowEx and FindWindowEx(nint, nint, string, string). These are fields and not constants, because C# has no IntPtr constants; don't compare handles with them by reference but with ==.
