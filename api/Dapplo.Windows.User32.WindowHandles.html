Dapplo.Windows.User32

Dapplo.Windows.User32.dll

The special window handle values of the Windows API, e.g. for the hWndInsertAfter of SetWindowPos(nint, nint, int, int, int, int, WindowPos), the hWnd of PostMessage(nint, uint, nint, nint) or the parent of CreateWindowEx and FindWindowEx(nint, nint, string, string). These are fields and not constants, because C# has no IntPtr constants; don't compare handles with them by reference but with ==.

HWND_BOTTOM

HWND_BOTTOM (1): SetWindowPos places the window at the bottom of the Z-order. A topmost window loses its topmost status and is placed at the bottom of all other windows.

public static readonly nint HWND_BOTTOM

HWND_BROADCAST

HWND_BROADCAST (0xFFFF): PostMessage, SendMessage and SendMessageTimeout deliver the message to all top-level windows, including disabled or invisible unowned windows, overlapped windows and pop-up windows, but not to child windows or message-only windows. Only broadcast messages registered with RegisterWindowMessage, or system messages meant for broadcasting.

HWND_MESSAGE

HWND_MESSAGE (-3): the parent for a message-only window (CreateWindowEx, SetParent), or with FindWindowEx to search the message-only windows.

HWND_NOTOPMOST

HWND_NOTOPMOST (-2): SetWindowPos places the window above all non-topmost windows, which is behind all topmost windows. This removes the topmost status, it has no effect when the window is already non-topmost.
