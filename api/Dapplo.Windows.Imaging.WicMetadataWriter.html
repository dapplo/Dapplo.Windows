Methods

AddRawBlock(WicMetadataRawBlock)

Write a metadata block from its raw bytes, e.g. a WicMetadataRawBlock of a decoded image, to carry it over unchanged. With a path (e.g. "/xmp" or "/ifd/xmp") the block is set at that path, without a path it is added as top-level block of the frame. Verified with the codecs of Windows: "/app1" and "/xmp" for JPEG, "/xmp" for PNG, "/ifd/xmp" for TIFF and JPEG XR (written as tag 700).

Set(string, object)

Set a value with the metadata query language, e.g. Set(WicMetadataPaths.Software(format), WicMetadataValue.AnsiString("Greenshot")) or Set("/xmp/dc:title", "Title"). Supported values: string (VT_LPWSTR), WicMetadataValue (VT_LPSTR or a vector of bytes), bool, the integer types, float, double, WicRational, WicSignedRational, DateTime and DateTimeOffset (FILETIME), Guid, byte[] (VT_BLOB), ushort[], uint[], int[] and string[]. Parent blocks which don't exist yet are created by WIC.
