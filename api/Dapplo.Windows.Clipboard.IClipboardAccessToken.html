Remarks

The clipboard can be used from any thread, no STA thread is needed. But Windows ties an opened clipboard to the thread which opened it: the token can only be used on the thread which opened the clipboard, and must be disposed on that thread (disposing it elsewhere throws an InvalidOperationException and leaves the clipboard open). Never await, ObserveOn or otherwise switch threads while holding the token, keep the usage short: while the token is held, no other application can access the clipboard. Prefer UseAsync<T>(Func<IClipboardAccessToken, T>, ClipboardAccessOptions, CancellationToken), which guarantees this.
