Examples

// The shield for a "needs administrator rights" button
using var shield = StockIcons.GetIcon<Bitmap>(StockIconId.Shield, 16);
// The error icon as the big image of a toast
using var error = StockIcons.GetIcon<Bitmap>(StockIconId.Error, 96);
error?.Save("error.png", ImageFormat.Png);

Remarks

This asks SHGetStockIconInfo for the file and index of the icon, and extracts it with SHDefExtractIcon in the requested size, so Windows picks (or scales) the best image of the icon for that size. All icon handles are destroyed before this returns.

SHGetStockIconInfo only applies LinkOverlay and Selected to an icon handle in one of the system sizes, so here they are applied to the extracted icon: the link overlay is the Link stock icon drawn over it in the same size, as the shell does, and selected blends the icon 50% with the system highlight color, as an image list does. Other flags are ignored, the method chooses what it asks Windows for.

Exceptions

ArgumentOutOfRangeException

size is not between 1 and MaxSize

NotSupportedException
