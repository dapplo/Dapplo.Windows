MoveMouseWheelAt(int, NativePoint, bool, bool)

Generate a mouse wheel movement at the specified location. Like MoveMouseWheel(int, NativePoint?, uint?) the cursor moves to the location, which is where the system delivers the wheel input. With restoreCursor the cursor is moved back to where it was afterwards, in the same SendInput call, so the wheel input is still processed at the location.

public static bool MoveMouseWheelAt(int wheelDelta, NativePoint location, bool restoreCursor, bool horizontal = false)

Parameters

wheelDelta int

int with the delta, one notch is 120 (WHEEL_DELTA); negative scrolls down, for the horizontal wheel negative scrolls left

location NativePoint

NativePoint, in screen coordinates, where the mouse wheel takes place

restoreCursor bool

true to move the cursor back to its current location after the wheel input

horizontal bool

true for a horizontal wheel movement (MOUSEEVENTF_HWHEEL)

Returns

bool

true when all input events were inserted into the input stream

Remarks

The location and the restored cursor position are physical screen coordinates; call this from a (per-monitor) DPI aware process, otherwise the system scales the coordinates and the cursor doesn't return to exactly the same place.
