What SHGetStockIconInfo returns (SHGSI_* flags). See SHGetStockIconInfo function.

[Flags]
public enum StockIconFlags : uint

Fields

Icon = 256

The large icon (default) or the small icon is returned in StockIconInfo.IconHandle (SHGSI_ICON), the caller destroys it with DestroyIcon

IconLocation = 0

The path and the icon index in that file are returned in StockIconInfo.Path and StockIconInfo.IconIndex (SHGSI_ICONLOCATION), this is always done

LargeIcon = 0

Modifies Icon: the large icon, the size of SM_CXICON (SHGSI_LARGEICON), the default

LinkOverlay = 32768

Modifies Icon: the link overlay is added to the icon (SHGSI_LINKOVERLAY)

Selected = 65536

Modifies Icon: the icon is blended with the system highlight color (SHGSI_SELECTED)

ShellIconSize = 4

Modifies LargeIcon or SmallIcon: the icon in the size the shell uses (SHGSI_SHELLICONSIZE)

SmallIcon = 1

Modifies Icon: the small icon, the size of SM_CXSMICON (SHGSI_SMALLICON)

SystemIconIndex = 16384

The index of the icon in the system image list is returned in StockIconInfo.SystemImageIndex (SHGSI_SYSICONINDEX)
