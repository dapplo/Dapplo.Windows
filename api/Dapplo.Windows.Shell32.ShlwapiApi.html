AssocQueryString(AssocF, AssocStr, string, string, char[], ref uint)

Searches for and retrieves a file or protocol association-related string from the registry. See AssocQueryStringW function. Use GetAssociationString(AssocStr, string, string, AssocF), which sizes the buffer.

public static extern int AssocQueryString(AssocF flags, AssocStr str, string pszAssoc, string pszExtra, char[] pszOut, ref uint pcchOut)

Parameters

flags AssocF

AssocF, e.g. IsProtocol when pszAssoc is a protocol

str AssocStr

AssocStr, the string to return

pszAssoc string

The extension (".html"), the protocol ("https"), a ProgID or an application, depending on the flags

pszExtra string

The verb, e.g. "open", for Command and Executable, can be null

pszOut char[]

The buffer which receives the string, null to get the required size

pcchOut uint

On entry the size of pszOut in characters, on exit the number of characters written or needed, including the terminating null

Returns

int

HRESULT: S_OK, S_FALSE when pszOut is null and the size is returned, E_POINTER when the buffer is too small (with NoTruncate), HRESULT_FROM_WIN32(ERROR_NO_ASSOCIATION) (0x80070483) when there is no association

GetAssociationString(AssocStr, string, string, AssocF)

Returns a file or protocol association string, e.g. the command which opens https addresses: GetAssociationString(AssocStr.Command, "https", "open", AssocF.IsProtocol). The buffer is sized to the string, it is never truncated.

public static string GetAssociationString(AssocStr str, string assoc, string extra = "open", AssocF flags = AssocF.None)

Parameters

str AssocStr

AssocStr, the string to return

assoc string

extra string

The verb, default "open", used for Command and Executable, can be null

flags AssocF

AssocF, e.g. IsProtocol for a protocol

Returns
