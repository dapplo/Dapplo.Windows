Classes

UiAutomationArea

An area of a window as UI Automation reports it: an element of the control view with its bounds, control type, name and the areas inside it. Immutable, a snapshot from FindAreasAsync(nint, int, int, TimeSpan?, CancellationToken).

UiAutomationAreas

Read the areas UI Automation knows inside a window (the parts of a browser page, an Electron, WPF or UWP app, an Office ribbon), e.g. to snap a region selection to them where the window has no child windows. Works on a window handle, not on a point, so it also works while another window (a full-screen selection window) covers the window.

UiAutomationScroller

Scrolls an element which supports the UI Automation ScrollPattern. This works for nearly every application which draws its own scroll bars, where GetWindowScroller(IInteropWindow, ScrollBarTypes, bool) returns null: Chromium / Electron, Firefox, WPF, WinUI, Office and the Explorer file list. Controls which have no ScrollPattern but expose their scroll bar as a UI Automation element (e.g. the Visual Studio editor) are scrolled with the mouse wheel, see IsScrollBarFallback. Create it with FromPoint(NativePoint, bool) or FromWindow(nint, bool); it has the same shape as WindowScroller, both implement IScroller.
