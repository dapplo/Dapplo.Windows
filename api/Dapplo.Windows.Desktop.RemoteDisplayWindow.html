Class RemoteDisplayWindow

Namespace
Dapplo.Windows.Desktop
Assembly
Dapplo.Windows.dll

Finds out if a window on the local desktop is the picture of a session on another machine, drawn by a remote display client: Citrix Workspace app, Remote Desktop (mstsc, msrdc / Windows App), VMware / Omnissa Horizon, Hyper-V vmconnect or a VNC viewer. Such a window is a bitmap for Windows: UI Automation has no text or elements for its content, so e.g. reading the text of the window has to fall back to OCR.

Remarks

The check uses the name of the executable of the process which owns the top-level window, and the class names of the window and its top-level window, so it is cheap and needs nothing of the remote display client. This is the opposite question of Dapplo.Windows.Citrix: WinFrame tells if the current process runs inside a Citrix session.

GetKind(nint)

Which remote display client draws the window, if any. The window and its top-level window (GA_ROOT) are checked, so a child window (e.g. the output window of a Remote Desktop session) gives the same answer as its top-level window.
