Fields

DI_COMPAT = 4

This flag is ignored.

DI_DEFAULTSIZE = 8

Draws the icon or cursor using the width and height specified by the system metric values for icons, if the cxWidth and cyWidth parameters are set to zero.

DI_IMAGE = 2

Draws the icon or cursor using the image.

DI_MASK = 1

Draws the icon or cursor using the mask.

DI_NOMIRROR = 16

Draws the icon as an unmirrored icon. By default, the icon is drawn as a mirrored icon if hdc is mirrored.

DI_NORMAL = DI_MASK | DI_IMAGE

Combination of DI_IMAGE and DI_MASK.
