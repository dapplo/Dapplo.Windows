Remarks

Opening a local .html file with ShellExecute starts the application of the .html association, which can be an editor. This reads the command of the https protocol (AssocQueryString with ASSOCF_IS_PROTOCOL, verb "open") and starts it with the target, a local path is passed as file:/// address.

Fields

SingleArgumentSwitch

The switch with which Chromium based browsers (Edge, Chrome) register their command: --single-argument %1. Everything after it is taken literally, quotes included, so the target must not be quoted there.

CreateStartInfo(string, string)

Creates the ProcessStartInfo for a browser command (as registered for a protocol) and a target. The program is the quoted part of the command, or the part up to the first space, the rest are the arguments, in which:

  • "%1" and %1 (and %L) are replaced with the quoted target,
  • after SingleArgumentSwitch they are replaced with the target without quotes, as everything after that switch is taken literally,
  • without a placeholder the quoted target is appended.

A rooted local path is passed as file:/// address, see ToAddress(string).
