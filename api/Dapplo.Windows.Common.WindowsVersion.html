WinVersion

Get the current windows version (Major.Minor.Build.0). This is retrieved with RtlGetVersion, so it is correct even when the host executable has no supportedOS entries in its manifest (in that case Environment.OSVersion reports 6.2 on Windows 8.1 and later, on .NET Framework).
