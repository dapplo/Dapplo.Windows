ForText(string)

Create the KeyboardInputs which type the text, as used by TypeText(string). Every UTF-16 code unit becomes a Unicode key down and key up (ForUnicodeKeyDown(char, uint?), ForUnicodeKeyUp(char, uint?)), a surrogate pair becomes two of these, the high surrogate first. Line breaks ("\r\n", "\n" or "\r") become a press of Return, "\t" a press of Tab, as most applications ignore these characters when they arrive as WM_CHAR without the key. All other control characters (IsControl(char), e.g. \0, \b, escape, form feed) are skipped: applications treat them as editing commands (backspace, cancel, Ctrl+C in a console) and not as text.

IsExtendedKey(VirtualKeyCode)

Check if the specified VirtualKeyCode is an extended key (E0 prefixed scan code), these need KEYEVENTF_EXTENDEDKEY when they are injected, otherwise Windows uses the non-extended (numpad) equivalent. Examples are the arrow keys, Insert, Delete, Home, End, PageUp, PageDown, RightControl, RightMenu (AltGr), Divide, NumLock, the Windows keys and the media keys.
