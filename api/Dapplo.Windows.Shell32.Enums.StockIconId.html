Enum StockIconId

Namespace
Dapplo.Windows.Shell32.Enums
Assembly
Dapplo.Windows.Shell32.dll

The Windows stock icons, the shell's own icons for error, warning, information, shield, folders, drives and more (SHSTOCKICONID). See SHSTOCKICONID enumeration. The numbering has gaps (14, 18-21, 24-27, 33-39, 41-46, 48, 107-131 and 141-180 aren't named), the values match shellapi.h of the Windows SDK.
