Namespace Dapplo.Windows.Imaging

Classes

WicCodecInfo

Immutable description of one WIC codec as reported by WIC, see WicCodecs

WicCodecNotFoundException

WIC has no codec for the container format or the stream (WINCODEC_ERR_COMPONENTNOTFOUND, 0x88982F50), or the codec is registered but can't be initialized (WINCODEC_ERR_COMPONENTINITIALIZEFAILURE, 0x88982F8B, e.g. the HEIF encoder without the HEVC video extension). This is a normal case, e.g. when a Store codec like JPEG XL or HEIF isn't installed, so callers can fall back. ErrorCode tells which.

WicCodecs

Discovery of the codecs of the Windows Imaging Component (WIC). Unlike the registry (HKCR\CLSID{7ED96837-96F0-4812-B211-F13C24117ED3}\Instance), which doesn't list the built-in codecs on newer Windows versions and never lists packaged (Store) codecs like HEIF/AVIF and WebP, this asks WIC itself, which reports all of them.

WicContainerFormats

The WIC container format GUIDs (GUID_ContainerFormat* of wincodec.h), compare with ContainerFormat or use for ContainerFormat. The codecs for HEIF (also AVIF), WebP, Raw and JPEG XL are Store extensions, which might not be installed: check with WicCodecs.

WicEncodeOptions

The options for Encode(Stream, WicEncodeOptions, nint, int, int, int, Guid)

WicEncodeResult

The result of an encoding

WicEncoderOption

An option of an encoder, see GetEncoderOptions(Guid)

WicFrameInfo

The first frame of a decoded image

WicImage

Encode and decode images with the Windows Imaging Component (WIC), without WPF, System.Drawing or other pixel libraries: pixels are passed as memory (pointer and stride) or row by row through a callback, streams are .NET streams. Every COM object is created per call and released before the call returns, the methods work from STA and MTA threads. When WIC has no codec for the container format or the stream, a WicCodecNotFoundException is thrown.

WicMetadata

The metadata of a decoded frame, read once while decoding (a snapshot, no COM object is kept). The paths are those of the WIC metadata query language with the names of the blocks, e.g. "/app1/ifd/{ushort=274}" for the orientation in a JPEG and "/ifd/xmp/dc:title" for the XMP title in a TIFF. The paths with the tags of the blocks, as WIC enumerates them (e.g. "/app1/{ushort=0}/{ushort=274}"), work for TryGet(string, out object) too. See the metadata query language and WicMetadataPaths.

WicMetadataBlock

A nested metadata reader (a block like "/app1" or "/app1/ifd/exif"), as a value in Items

WicMetadataFormats

The WIC metadata format GUIDs (GUID_MetadataFormat* of wincodecsdk.h) of the blocks which are used most, see Format.

WicMetadataIssue

Metadata which an encoder didn't accept, see MetadataIssues

WicMetadataPaths

The metadata query paths per container: the same EXIF tag has a different path in each container, e.g. Software is "/app1/ifd/{ushort=305}" in a JPEG and "/ifd/{ushort=305}" in a TIFF or JPEG XR. Every method returns null when the container has no such path (or it isn't known to work). See doc/articles/imaging.md for which paths the codecs of Windows accept.

WicMetadataRawBlock

The raw bytes of a metadata block

WicMetadataValue

A value with an explicit PROPVARIANT type, for Set(string, object)

WicMetadataWriter

Writes the metadata of the frame which is encoded, see Metadata. Everything the encoder doesn't accept is skipped and reported in Issues, it never fails the encoding. Only valid during the callback.

WicPixelFormats

The WIC pixel format GUIDs (GUID_WICPixelFormat* of wincodec.h) which are used most. Any other WIC pixel format GUID can be used too.

WicVendors

The WIC vendor GUIDs of wincodec.h, compare them with VendorGuid

Structs

WicRational

An unsigned rational, e.g. an EXIF RATIONAL like XResolution or ExposureTime. WIC stores it as VT_UI8 with the numerator in the low and the denominator in the high 32 bits.

WicSignedRational

A signed rational, e.g. an EXIF SRATIONAL like ExposureBiasValue. WIC stores it as VT_I8 with the numerator in the low and the denominator in the high 32 bits.

WicPixelBufferProvider

Supplies the memory for a decoded image once its size is known, e.g. the Scan0 of a locked GDI+ Bitmap

WicRowConsumer

Receives decoded rows of pixels: the rows [top, top + count), row i starts at i * sourceStride

WicRowProvider

Supplies rows of pixels for an encoder: copy the rows [top, top + count) into destination, row i starts at i * destinationStride. Each row has width * bits per pixel / 8 bytes (rounded up), the bytes between rows (stride padding) don't matter. The span ends after the last row, so it can be shorter than count * destinationStride.
