Namespace Dapplo.Windows.SystemState

Classes

PowerBroadcastListener

Provides an observable stream of power broadcast events from the Windows message queue. Listens for WM_POWERBROADCAST messages and exposes them as an IObservable<T> of PowerBroadcastEvent values. See WM_POWERBROADCAST message and System Wake-Up Events

PowerManagementApi

Provides access to Windows power management API functions.

SleepBlocker

Keeps the system (and optionally the display) awake while this object is alive, using a power request (PowerCreateRequest / PowerSetRequest). Dispose it to allow the system to sleep again.

SystemStateApi

Provides access to Windows system state APIs, including thread execution state and waitable timer functions.

WaitableTimer

A managed wrapper around a Windows waitable timer that can optionally wake the system from sleep or hibernation. See Waitable Timer Objects The native handle is owned by a SafeWaitHandle, so it is released even when Dispose is forgotten, and disposing while another thread waits does not close the handle under the wait.
