RmGetList(int, out uint, ref uint, RmProcessInfo[], out RmRebootReason)

Gets a list of all applications and services that are currently using resources that have been registered with the Restart Manager session. See RmGetList function

public static extern int RmGetList(int dwSessionHandle, out uint pnProcInfoNeeded, ref uint pnProcInfo, RmProcessInfo[] rgAffectedApps, out RmRebootReason lpdwRebootReasons)

Parameters

dwSessionHandle int

A handle to an existing Restart Manager session.

pnProcInfoNeeded uint

A pointer to an array size necessary to receive RM_PROCESS_INFO results. If the buffer size is insufficient, this parameter receives the size required.

pnProcInfo uint

A pointer to the total number of RM_PROCESS_INFO structures that are returned to the caller.

rgAffectedApps RmProcessInfo[]

An array of RM_PROCESS_INFO structures that list the applications and services using resources that have been registered with the session. This parameter can be NULL if lpdwRebootReasons is not NULL.

lpdwRebootReasons RmRebootReason

Pointer to location that receives a value of the RM_REBOOT_REASON enumeration that describes the reason a system restart is needed.

Returns

int

Returns ERROR_SUCCESS (0) on success. Returns ERROR_MORE_DATA if the rgAffectedApps buffer is too small. Returns an error code on other failures.

RmRegisterResources(int, uint, string[], uint, RmUniqueProcess[], uint, string[])

Registers resources to a Restart Manager session. The Restart Manager uses the list of resources registered with the session to determine which applications and services must be shut down and restarted. See RmRegisterResources function

public static extern int RmRegisterResources(int dwSessionHandle, uint nFiles, string[] rgsFilenames, uint nApplications, RmUniqueProcess[] rgApplications, uint nServices, string[] rgsServiceNames)

Parameters

dwSessionHandle int

A handle to an existing Restart Manager session.

nFiles uint

The number of files being registered.

rgsFilenames string[]

An array of null-terminated strings of full filename paths. This parameter can be NULL if nFiles is 0.

nApplications uint

The number of processes being registered.

rgApplications RmUniqueProcess[]

An array of RM_UNIQUE_PROCESS structures. This parameter can be NULL if nApplications is 0.

nServices uint

The number of services to be registered.

rgsServiceNames string[]

An array of null-terminated strings of service short names. This parameter can be NULL if nServices is 0.

Returns

int

Returns ERROR_SUCCESS (0) on success, or an error code on failure.

RmStartSession(out int, int, StringBuilder)

Starts a new Restart Manager session. See RmStartSession function

public static extern int RmStartSession(out int pSessionHandle, int dwSessionFlags, StringBuilder strSessionKey)

Parameters

pSessionHandle int

A pointer to the handle of a Restart Manager session. The session handle can be passed in subsequent calls to the Restart Manager API.

dwSessionFlags int

Reserved. This parameter should be 0.

strSessionKey StringBuilder

A null-terminated string that contains the session key to the new session. The string must be allocated before calling this function and should be at least CCH_RM_SESSION_KEY characters in length.

Returns

int

Returns ERROR_SUCCESS (0) on success, or an error code on failure.
