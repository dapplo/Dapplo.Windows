RemoteDisplay

The remote display client which draws the window (GetKind(nint)), None when the window shows its own content. A remote display window (Citrix, Remote Desktop, Horizon, ...) is a picture for Windows, UI Automation has no text for its content: the snapshot is then never complete and the text has to come from OCR.
