Describes the format of the raw input from a Human Interface Device (HID). See RAWHID structure This is only the fixed part of the structure, the HID reports (bRawData) follow it inline and have a variable length. They are available as HidData, or via TryParseRawInput(byte[], out RawInput, out byte[]).
