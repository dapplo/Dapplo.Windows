An area of a window as UI Automation reports it: an element of the control view with its bounds, control type, name and the areas inside it. Immutable, a snapshot from FindAreasAsync(nint, int, int, TimeSpan?, CancellationToken).

GetAreasAt(NativePoint)

The areas which contain the point, from the deepest one to this one (the root): snap to the first and let the user step up the chain. When siblings overlap, the one which comes last in Children (drawn on top) is taken. Pure geometry on the snapshot, no UI Automation calls. A point on the right or bottom edge of an area is outside of it.
