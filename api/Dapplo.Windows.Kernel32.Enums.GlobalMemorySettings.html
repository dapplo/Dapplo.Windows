Fields

Fixed = 0

Allocates fixed memory. The return value is a pointer.

Movable = 2

Allocates movable memory. Memory blocks are never moved in physical memory, but they can be moved within the default heap. The return value is a handle to the memory object. To translate the handle into a pointer, use the GlobalLock function. This value cannot be combined with Fixed.

ZeroInit = 64

Initializes memory contents to zero.
