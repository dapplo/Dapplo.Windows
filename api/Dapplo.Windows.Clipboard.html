ClipboardContents

Describes the complete content for the clipboard: one or more formats of the same data, and optionally the clipboard history / cloud clipboard options. Build it before opening the clipboard, then place it in one short operation with ReplaceContents(ClipboardContents, nint, int, TimeSpan?, TimeSpan?) or ReplaceContents(IClipboardAccessToken, ClipboardContents), which always clear the clipboard first.

ClipboardContentsExtensions

ClipboardRenderFormatRequest

ClipboardSnapshot

A copy of clipboard formats in memory, read in one short clipboard session with ReadSnapshotAsync(IEnumerable<string>, ClipboardAccessOptions, CancellationToken) or ReadSnapshot(IClipboardAccessToken, IEnumerable<string>, long). Decoding, saving or uploading the data happens afterwards, while other applications can use the clipboard again. The snapshot doesn't change when the clipboard changes, and can be used on any thread. Request only the formats you need, reading a format makes the application which copied render it: AvailableFormats(IEnumerable<string>, int) selects them without opening the clipboard.

ClipboardSnapshotExtensions

Read a ClipboardSnapshot with an open clipboard

ClipboardStreamExtensions

These are extensions to work with the clipboard. The streams returned by GetAsStream and TryGetAsStream contain a copy of the clipboard content (the complete clipboard memory allocation, which can be larger than the actual data). This costs memory for the size of the content, but the stream can't outlive the clipboard lock and stays valid after the access token is disposed.

ClipboardStringExtensions

These are extensions to work with the clipboard

ClipboardUpdateInformation

Information about what the clipboard contained at the most recent clipboard update. This information is collected without opening the clipboard (GetClipboardSequenceNumber, GetClipboardOwner and GetUpdatedClipboardFormats), to read the content use Access(nint, int, TimeSpan?, TimeSpan?) or AccessAsync(nint, int, TimeSpan?, TimeSpan?, CancellationToken).

DataObjectReader

Reads an OLE data object (IDataObject), from drag and drop or from GetOleDataObject(int, TimeSpan?). It supports what the Win32 clipboard API can't: formats with an index (lindex), IStream data and virtual files (FileGroupDescriptorW + FileContents, e.g. Outlook attachments). As IClipboardDataSource the same read helpers work as for the clipboard and snapshots.

DibImage

A decoded device independent bitmap (CF_DIB / CF_DIBV5), normalized to top-down 32 bpp BGRA with straight alpha, so it can be handed to any imaging library (ImageSharp, System.Drawing, SkiaSharp, WPF, …).

VirtualFile

A file which only exists in the data object ("virtual file"), e.g. an Outlook attachment or an image dragged from some browsers: described by FileGroupDescriptorW, its content is the FileContents format with the index of the file.

Interfaces

IClipboardAccessToken

This interface is returned by ClipboardNative.Access() and ClipboardNative.AccessAsync(). When you got a IClipboardAccessToken, you can access the clipboard, until it's disposed. Don't forget to dispose this!!!

IClipboardDataSource

Read access to clipboard-like data: the open clipboard (AsDataSource(IClipboardAccessToken)), a ClipboardSnapshot, or other data such as drag and drop data. The extension methods in ClipboardDataSourceExtensions read text, bytes and file names from every source, so one piece of code works for all of them.
