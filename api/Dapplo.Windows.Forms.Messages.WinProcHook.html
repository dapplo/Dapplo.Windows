Delegate WinProcHook

Namespace
Dapplo.Windows.Forms.Messages
Assembly
Dapplo.Windows.Forms.dll

A hook for the window procedure of a WinProcListener, it has the same signature as the WPF HwndSourceHook.

public delegate nint WinProcHook(nint hWnd, int msg, nint wParam, nint lParam, ref bool handled)

Parameters

hWnd nint

IntPtr with the window handle

msg int

int with the message

wParam nint

IntPtr with the wParam

lParam nint

IntPtr with the lParam

handled bool

set to true to stop the processing of the message, the return value is then the result for Windows

Returns

nint

IntPtr with the result of the message, only used when handled is set to true
