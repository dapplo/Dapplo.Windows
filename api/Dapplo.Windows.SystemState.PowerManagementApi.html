The shutdown reason which is used by Shutdown(bool, uint) and Restart(bool, uint): SHTDN_REASON_MAJOR_OTHER | SHTDN_REASON_MINOR_OTHER | SHTDN_REASON_FLAG_PLANNED, which logs a planned shutdown. See System Shutdown Reason Codes

EnableShutdownPrivilege()

Enables the SE_SHUTDOWN_NAME privilege for the current process. Interactive users hold this privilege, but it is disabled by default, and ExitWindowsEx (shutdown / restart) or InitiateSystemShutdown require it to be enabled.

public static bool EnableShutdownPrivilege()

Returns

bool

true if the privilege is enabled, false if the user doesn't hold it or the token could not be adjusted (see Marshal.GetLastWin32Error).

ExitWindowsEx(ExitWindowsFlags, uint)

Logs off the interactive user, shuts down the system, or shuts down and restarts the system. See ExitWindowsEx function

public static extern bool ExitWindowsEx(ExitWindowsFlags uFlags, uint dwReason = 0)

Parameters

uFlags ExitWindowsFlags

The shutdown type. One or more ExitWindowsFlags values.

dwReason uint

The reason for initiating the shutdown. This parameter must be one of the system shutdown reason codes. If this parameter is zero, the SHTDN_REASON_FLAG_PLANNED reason code will not be set, and therefore the default action is to create an "unplanned" shutdown.

bool

Restart(bool, uint)

Restarts the system (EWX_REBOOT). This enables the SE_SHUTDOWN_NAME privilege of the process, which the user must hold.

public static bool Restart(bool force = false, uint reason = 2147483648)

Parameters

force bool

If true, forces running applications to close (EWX_FORCE), which can cause them to lose data. Otherwise applications which don't respond are only terminated after a timeout (EWX_FORCEIFHUNG).

reason uint

The shutdown reason which is logged, default is a planned shutdown with ShutdownReasonPlannedOther

Returns

bool

true if the operation was initiated successfully, otherwise see Marshal.GetLastWin32Error (e.g. 1314 ERROR_PRIVILEGE_NOT_HELD).

SetSuspendState(bool, bool, bool)

Suspends the system by transitioning it to sleep mode or hibernation. See SetSuspendState function

public static extern bool SetSuspendState(bool hibernate, bool forceCritical, bool disableWakeEvent)

Parameters

hibernate bool

If true, the system hibernates. If false, the system is suspended.

forceCritical bool

If true, the system is suspended or hibernated immediately without sending the WM_POWERBROADCAST message. If false, the function broadcasts a WM_POWERBROADCAST message with the PBT_APMSUSPEND parameter value. Applications that have registered for power notification will have the opportunity to prevent the suspend.

disableWakeEvent bool

If true, the system disables all wake events. If false, enabled wake events remain enabled.

Returns

bool

true if the function succeeds, otherwise false.
