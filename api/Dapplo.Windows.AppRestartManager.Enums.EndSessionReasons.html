Fields

ENDSESSION_CLOSEAPP = 1

The application is using a file that must be replaced, the system is being serviced, or system resources are exhausted. This is what the Restart Manager sends when it wants the application to close.

ENDSESSION_CRITICAL = 1073741824

The application is forced to shut down because a system component is being updated or a critical system event requires the application to close.

ENDSESSION_LOGOFF = 2147483648

The user is logging off.

None = 0

The system is shutting down or restarting (reason was not specified).
