GetHResult(Win32Error)

Convert a Win32Error to an HResult, this is the equivalent of the HRESULT_FROM_WIN32 macro. Success (0) maps to S_OK, values which already are an HRESULT (negative when interpreted as int) are returned unchanged, all other values are mapped to 0x8007xxxx (FACILITY_WIN32 with the severity bit set).
