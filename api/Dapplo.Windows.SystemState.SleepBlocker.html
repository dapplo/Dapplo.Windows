Keeps the system (and optionally the display) awake while this object is alive, using a power request (PowerCreateRequest / PowerSetRequest). Dispose it to allow the system to sleep again.

Remarks

Unlike SetThreadExecutionState, a power request is not bound to the calling thread: it can be created and disposed on any thread, e.g. before and after an await. Several blockers can be active at the same time, the system can sleep when all of them are disposed (or when the process exits). The reason is shown by powercfg /requests. See PowerCreateRequest function
