See ICONINFO structure Contains information about an icon or a cursor.

When filled by GetIconInfo, the two bitmaps (mask and color) are created for the caller, who must delete them exactly once. The properties BitmaskBitmap and ColorBitmap only expose the raw, non-owning, handles. Use TakeBitmaps(out SafeHBitmapHandle, out SafeHBitmapHandle) to transfer the ownership into SafeHandles, or DeleteBitmaps() to delete them. As this is a struct, copies share the same handles: only take or delete the bitmaps on one copy. When used for CreateIconIndirect, the bitmaps stay owned by the caller (the system copies them).

Properties

BitmaskBitmap

The icon bitmask bitmap. If this structure defines a black and white icon, this bitmask is formatted so that the upper half is the icon AND bitmask and the lower half is the icon XOR bitmask. Under this condition, the height should be an even multiple of two. If this structure defines a color icon, this mask only defines the AND bitmask of the icon.

public nint BitmaskBitmap { get; set; }

Property Value

nint

Remarks

This is the raw handle, it is not owned by this struct nor by the caller of the getter, see TakeBitmaps(out SafeHBitmapHandle, out SafeHBitmapHandle).

ColorBitmap

A handle to the icon color bitmap. This member can be optional if this structure defines a black and white icon. The AND bitmask of hbmMask is applied with the SRCAND flag to the destination; subsequently, the color bitmap is applied (using XOR) to the destination by using the SRCINVERT flag.

public nint ColorBitmap { get; set; }

Property Value

nint

Remarks

This is the raw handle, it is not owned by this struct nor by the caller of the getter, see TakeBitmaps(out SafeHBitmapHandle, out SafeHBitmapHandle). IntPtr.Zero for a monochrome icon or cursor.

Hotspot

The x and y coordinates of a cursor's hot spot. If this structure defines an icon, the hot spot is always in the center of the icon, and this member is ignored.

public NativePoint Hotspot { get; set; }

Property Value

NativePoint

IsIcon

Specifies whether this structure defines an icon or a cursor. A value of TRUE specifies an icon; FALSE specifies a cursor.

public bool IsIcon { get; set; }

Property Value

bool

Methods

DeleteBitmaps()

Deletes the bitmaps which were created by GetIconInfo, and clears the handles in this struct. Only call this on one copy of the struct, and not when the ownership was already taken with TakeBitmaps(out SafeHBitmapHandle, out SafeHBitmapHandle).

public void DeleteBitmaps()

TakeBitmaps(out SafeHBitmapHandle, out SafeHBitmapHandle)

Transfer the ownership of the bitmaps, which were created by GetIconInfo, to the caller. The handles in this struct are cleared, so calling this method (or DeleteBitmaps()) again on the same variable does nothing.

public void TakeBitmaps(out SafeHBitmapHandle bitmaskBitmap, out SafeHBitmapHandle colorBitmap)
