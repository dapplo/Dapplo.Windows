IsPacket

True if this is a VK_PACKET event: not a key, but a Unicode character (one UTF-16 code unit, see PacketCharacter) which was sent with KEYEVENTF_UNICODE, e.g. by TypeText(string), an IME, an on-screen keyboard or a remote desktop client. A character outside the Basic Multilingual Plane arrives as two packets (a high and a low surrogate). The KeyCombinationHandler and the KeySequenceHandler ignore these events.

public bool IsPacket { get; }
