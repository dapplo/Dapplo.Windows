Class WinProcListener

Namespace
Dapplo.Windows.Forms.Messages
Assembly
Dapplo.Windows.Forms.dll

This is a Listener for WinProc messages of a Control, it subclasses the window of the control. It follows the handle of the control: when the handle is recreated (e.g. by changing ShowInTaskbar, RightToLeft or FormBorderStyle) the new handle is subclassed.
