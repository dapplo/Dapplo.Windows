AlphaBlend(ref Bgra32, in Bgra32)

Alpha blends a source pixel onto a target pixel, using the Porter-Duff "source over" operator. Both pixels use straight (non-premultiplied) alpha, as in Format32bppArgb.

public static void AlphaBlend(ref Bgra32 target, in Bgra32 source)

Parameters

target Bgra32

The target pixel to blend onto (modified in place), straight alpha.

source Bgra32

The source pixel to blend from, straight alpha.

Remarks

When the target is opaque (A = 255), this is the classic src * a + dst * (1 - a). For a (semi-)transparent target the resulting alpha is a_src + a_dst * (1 - a_src) and the colors are weighted accordingly. For a target which has no alpha channel (e.g. Format32bppRgb), set target.A to 255 before blending.

AlphaBlendPremultiplied(ref Bgra32, in Bgra32)

Alpha blends a source pixel onto a target pixel, using the Porter-Duff "source over" operator. Both pixels use premultiplied alpha, as in Format32bppPArgb: result = src + dst * (1 - a_src) for all channels.
