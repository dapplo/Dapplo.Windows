PlayWave(byte[])

Play WAVE data (a complete .wav file) asynchronously. The wave data is copied into unmanaged memory which is kept alive until the next call to PlayWave(byte[]) or StopPlaying(), so the passed byte[] can be reused or collected directly after this call. Any sound which is currently playing is stopped first. See PlaySound(xxx, SND_MEMORY | SND_ASYNC) is almost always a bad idea.

public static bool PlayWave(byte[] soundBytes)

PlayWave(nint, SoundSettings)

Play WAVE data from unmanaged memory, Memory is always added to the settings. Note: the caller owns the memory, when Async is used it must stay valid until the sound has finished or was stopped with StopPlaying(). Prefer PlayWave(byte[]), which takes care of this.
