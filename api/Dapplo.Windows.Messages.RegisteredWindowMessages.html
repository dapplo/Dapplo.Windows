GetName(uint)

Get the name of a window message: for a message registered with Register(string) (0xC000 through 0xFFFF) this is the registered name, for the other messages the name of the WindowsMessages value (or the number, when it has no name).

public static string GetName(uint messageId)

Parameters

messageId uint

uint with the message id, e.g. as returned by Register(string)

Returns

string

string with the name, null when the id is in the registered range but no message with this id was registered

Register(string)

Register a window message, which is unique on the desktop: every process which registers the same name gets the same id. Use this e.g. to communicate between instances of an application with PostMessage / SendMessage.

public static uint Register(string name)

Parameters

name string

string with the unique name of the message, e.g. "MyApp.ShowMainWindow"

Returns

uint

uint with the message id, in the range 0xC000 through 0xFFFF, or 0 when it failed (use Marshal.GetLastWin32Error for the reason)
