GetChildren(IInteropWindow, bool)

Get the direct children of the specified interopWindow in Z-order, from top (front) to bottom (back), this is not lazy! The children are a snapshot taken with GetTopWindows(IInteropWindow), the result is stored in Children and returned from there until forceUpdate is true. Use GetDescendants(IInteropWindow) to get the children of the children too. The children of the desktop window are the top-level windows, these have no parent (Parent is IntPtr.Zero).

PostMessage(IInteropWindow, WindowsMessages, nint, nint)

Post a message to the window: it is placed in the message queue of the thread which created the window, this doesn't wait until it's processed. Use this e.g. for WM_CLOSE, so a window which shows a "save changes?" dialog doesn't block the caller. Don't post messages with pointers to memory (e.g. WM_SETTEXT), the memory might be gone before the message is processed.

public static bool PostMessage(this IInteropWindow interopWindow, WindowsMessages windowsMessage, nint wParam = 0, nint lParam = 0)

Parameters

interopWindow IInteropWindow

InteropWindow

windowsMessage WindowsMessages

WindowsMessages

wParam nint

IntPtr, pointer-sized message-specific information, default IntPtr.Zero

lParam nint

IntPtr, pointer-sized message-specific information, default IntPtr.Zero

Returns

bool

true if the message was posted, false if not (e.g. the window doesn't exist, the message queue is full, or UIPI blocks it), use Marshal.GetLastWin32Error for the reason

PrintWindow(IInteropWindow)

Return a Bitmap representing the Window! As GDI+ draws it, it will be without Aero borders! The window is printed with its complete window rectangle, and cropped to the (DWM corrected) bounds of GetInfo(IInteropWindow, bool, bool), so the invisible resize borders are not part of the result. Dapplo.Windows.Wpf has PrintWindowAsBitmapSource for a WPF BitmapSource.
