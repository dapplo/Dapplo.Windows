AlphaBlend(ref Bgr24, in Bgra32)

Alpha blends a source pixel with alpha channel onto this target pixel. Since Bgr24 has no alpha channel, the result is always opaque. The source must use straight (non-premultiplied) alpha, convert premultiplied pixels with ToStraight() first.
