AddToCurrentContents(IClipboardAccessToken, ClipboardContents)

Add the formats of the contents to the current content of the clipboard, without clearing it. This is only allowed when the clipboard content was placed by the window of the token (e.g. with ReplaceContents(IClipboardAccessToken, ClipboardContents) or ClearContents before), adding formats to the content of another application would mix two unrelated contents.

ReplaceContents(IClipboardAccessToken, ClipboardContents)

Replace the content of the clipboard: clears the clipboard (the window of the token becomes the owner) and places all formats of the contents. If placing a format fails, the clipboard is cleared again and the exception is rethrown: other applications never see half of the content.
