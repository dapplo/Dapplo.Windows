CreateWaitableTimer(nint, bool, string)

Creates or opens a waitable timer object. See CreateWaitableTimer function

public static extern SafeWaitHandle CreateWaitableTimer(nint lpTimerAttributes, bool bManualReset, string lpTimerName)

Parameters

lpTimerAttributes nint

A pointer to a SECURITY_ATTRIBUTES structure. If this parameter is Zero, the timer handle cannot be inherited by child processes.

bManualReset bool

If true, creates a manual-reset notification timer. If false, creates a synchronization timer.

lpTimerName string

The name of the timer object. If null, creates an unnamed timer.

Returns

SafeWaitHandle

If the function succeeds, the return value is a handle to the timer object, which is closed when the SafeWaitHandle is disposed. If the function fails, the returned handle is invalid (IsInvalid). Call GetLastError for extended error information.

SetThreadExecutionState(ThreadExecutionStateFlags)

Enables an application to inform the system that it is in use, thereby preventing the system from entering sleep or turning off the display while the application is running. See SetThreadExecutionState function

public static extern ThreadExecutionStateFlags SetThreadExecutionState(ThreadExecutionStateFlags esFlags)

Parameters

esFlags ThreadExecutionStateFlags

The thread's execution requirements. Can be a combination of ThreadExecutionStateFlags.

Returns

ThreadExecutionStateFlags

If the function succeeds, the return value is the previous thread execution state. If the function fails, the return value is 0.

Remarks

The state set with ES_CONTINUOUS belongs to the calling thread: it is only reset by a call on the same thread, and it ends when that thread exits. Don't use this from thread pool threads or async code, use PreventSleep(string) / SleepBlocker instead.

SetWaitableTimer(SafeWaitHandle, ref long, int, nint, nint, bool)

Activates the specified waitable timer. When the due time arrives, the timer is signaled and the optional completion routine is called. See SetWaitableTimer function

public static extern bool SetWaitableTimer(SafeWaitHandle hTimer, ref long pDueTime, int lPeriod, nint pfnCompletionRoutine, nint lpArgToCompletionRoutine, bool fResume)

Parameters

hTimer SafeWaitHandle

A handle to the timer object. The CreateWaitableTimer or OpenWaitableTimer function returns this handle.

pDueTime long

The time after which the state of the timer is to be set to signaled. This must be a negative value expressed in 100-nanosecond intervals (e.g., -10000000 for 1 second). A positive value specifies an absolute time in UTC.

lPeriod int

The period of the timer, in milliseconds. If zero, the timer is signaled once. If greater than zero, the timer is periodic.

pfnCompletionRoutine nint

A pointer to an optional completion routine. If Zero, no routine is called.

lpArgToCompletionRoutine nint

A pointer to a structure that is passed to the completion routine. Ignored if pfnCompletionRoutine is null.

fResume bool

If true and the system supports it, restores a system in suspended sleep or hibernation when the timer fires. No privilege is needed, but the wake only happens when the "Allow wake timers" power setting is enabled. If the system does not support a restore, the call succeeds but GetLastError returns ERROR_NOT_SUPPORTED.

Returns

bool

true if the function succeeds; otherwise false.
