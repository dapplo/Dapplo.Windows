DrawCursorOnBitmap(Bitmap, CapturedCursor, NativePoint, NativeSize)

Draws a captured cursor onto a bitmap at the specified position using pixel-level bitmap operations. This method is more reliable than DrawCursorOnGraphics when working directly with Bitmap objects.

public static void DrawCursorOnBitmap(Bitmap targetBitmap, CapturedCursor cursor, NativePoint position, NativeSize destinationSize = default)

Parameters

targetBitmap Bitmap

The bitmap to draw the cursor onto.

cursor CapturedCursor

The captured cursor data to draw.

position NativePoint

The position of the top-left corner of the cursor image, this is NOT offset by the hot spot.

destinationSize NativeSize

Optional size to scale the cursor. If empty, uses the cursor's natural size.

Remarks

This method uses typed Span-based pixel access (Bgra32/Bgr24) for efficient and readable bitmap manipulation. It supports both modern alpha-blended cursors and legacy XOR/mask cursors. For legacy cursors, it properly applies the AND mask followed by the XOR operation to achieve the correct visual effect. Alpha cursors are blended with the Porter-Duff "over" operator, taking the (premultiplied) alpha of the target into account.

Basic usage: 
// Capture the current cursor
if (CursorHelper.TryGetCurrentCursor(out var cursor))
{
    // Create or use an existing bitmap
    var bitmap = new Bitmap(800, 600, PixelFormat.Format32bppArgb);

    // Draw the cursor with its hot spot at the mouse position (100, 100)
    CursorHelper.DrawCursorOnBitmap(bitmap, cursor, new NativePoint(100 - cursor.HotSpot.X, 100 - cursor.HotSpot.Y));

    // Optionally scale the cursor
    CursorHelper.DrawCursorOnBitmap(bitmap, cursor, new NativePoint(200, 200), new NativeSize(64, 64));

    cursor.Dispose();
}

Exceptions

ArgumentNullException

Thrown when targetBitmap is null.

NotSupportedException

Thrown when the target bitmap's pixel format is not supported.

DrawCursorOnGraphics(Graphics, CapturedCursor, NativePoint, NativeSize)

Draws the specified cursor image onto the provided graphics context at the given position, applying appropriate blending techniques based on the cursor type.

public static void DrawCursorOnGraphics(Graphics targetGraphics, CapturedCursor cursor, NativePoint position, NativeSize destinationSize = default)

Parameters

targetGraphics Graphics

The graphics context where the cursor will be drawn. This must not be null.

cursor CapturedCursor

The cursor to be drawn, represented as a CapturedCursor containing the color and mask layers.

position NativePoint

The position (in world coordinates of the graphics) of the top-left corner of the cursor image. This is NOT offset by the hot spot, to draw the cursor at the mouse location pass the mouse location minus HotSpot (scaled with destinationSize when scaling).

destinationSize NativeSize

NativeSize, when empty the cursor.Size is used

Remarks

This method supports both modern alpha cursors and legacy XOR/mask cursors, utilizing different drawing strategies based on the cursor's properties. Modern cursors are drawn with GDI+ and respect the full transformation of the Graphics, legacy cursors are drawn with StretchBlt (AND/XOR) at the position and size transformed to device coordinates, rotations and shears are not supported for these.

GetCursorBaseSize()

Gets the base size of the mouse cursor, in pixels, as configured by the user in the system settings.

public static int GetCursorBaseSize()

Returns

int

The size of the mouse cursor in pixels. Returns 32 if the value cannot be retrieved from the system settings.

Remarks

This method reads the 'CursorBaseSize' value from the Windows Registry under 'Control Panel\Cursors'. If the value is not found or an error occurs while accessing the registry, a default size of 32 pixels is returned.

TryGetCurrentCursor(out CapturedCursor)

Attempts to retrieve information about the current cursor and capture its visual and positional properties.

public static bool TryGetCurrentCursor(out CapturedCursor result)

Parameters

result CapturedCursor

When this method returns, contains a CapturedCursor instance populated with details about the current cursor, including its size, hotspot, and image layers. This parameter is passed uninitialized.

Returns

bool

true if the current cursor information was successfully retrieved and captured; otherwise, false.

Remarks

This method captures both system and custom cursors, ensuring the cursor is visible before extracting its details. For system cursors, it attempts to load a high-DPI version to improve image quality. The captured information includes the cursor's size, hotspot, and image layers, which can be used for further processing or display.
