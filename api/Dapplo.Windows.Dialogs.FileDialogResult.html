Remarks

A result is either a cancellation (WasCancelled is true) or a successful selection (WasCancelled is false).

If the dialog fails unexpectedly (e.g. COM error, platform not supported), the builder's ShowDialog method throws — a FileDialogResult is never returned for failures. This makes it easy to distinguish the three cases: 

FileDialogResult result;
try
{
    result = new FileOpenDialogBuilder().AddFilter("All files", "*.*").ShowDialog();
}
catch (System.Runtime.InteropServices.COMException ex)
{
    // Unexpected COM failure — log or rethrow.
    logger.LogError(ex, "Dialog failed: {Hr}", ex.ErrorCode);
    return;
}
catch (System.PlatformNotSupportedException)
{
    // Non-Windows OS — fall back to a text input.
    return;
}

if (result.WasCancelled)
    return; // User pressed Cancel or Escape — not an error.

string path = result.SelectedPath; // guaranteed non-null here
