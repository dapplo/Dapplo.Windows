Methods

ProcessMessages(MessageProc, nint, uint?, uint?)

This processes messages, so a console application can use message based functionality, like low level keyboard events. The loop is very basic: it ends when WM_QUIT is received (e.g. after PostQuitMessage) or when the handler returns false.

public static void ProcessMessages(MessageLoop.MessageProc handler = null, nint hWnd = 0, uint? wMsgFilterMin = null, uint? wMsgFilterMax = null)

Parameters

handler MessageLoop.MessageProc

An optional function which is called after each message was dispatched, return false to stop the loop

hWnd nint

IntPtr with the window handle to get the messages for

wMsgFilterMin uint?

The integer value of the lowest message value to be retrieved. Use WM_KEYFIRST (0x0100) to specify the first keyboard message or WM_MOUSEFIRST (0x0200) to specify the first mouse message.

wMsgFilterMax uint?

The integer value of the highest message value to be retrieved. Use WM_KEYLAST to specify the last keyboard message or WM_MOUSELAST to specify the last mouse message.

Remarks

The handler is called AFTER the message was translated and dispatched to its window procedure, so it can observe messages (and stop the loop) but not filter or intercept them.

Exceptions

Win32Exception

When GetMessage fails, e.g. because hWnd is not a valid window of this thread
