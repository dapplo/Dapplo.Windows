NativePoint

NativePoint represents the native POINT structure for calling native methods. It has conversions from and to System.Drawing.Point (the conversions from and to the WPF types are extension methods in Dapplo.Windows.Wpf)

NativePointFloat

NativePoint represents the native POINT structure for calling native methods. It has conversions from and to System.Drawing.Point (the conversions from and to the WPF types are extension methods in Dapplo.Windows.Wpf)

NativeRect

NativeRect represents the native RECT structure for calling native methods. See RECT struct It has conversions from and to System.Drawing.Rectangle (the conversions from and to the WPF types are extension methods in Dapplo.Windows.Wpf)

NativeRectFloat

NativeRect represents the native RECTF structure for calling native methods. See RectF class It has conversions from and to System.Drawing.RectangleF (the conversions from and to the WPF types are extension methods in Dapplo.Windows.Wpf)

NativeSize
