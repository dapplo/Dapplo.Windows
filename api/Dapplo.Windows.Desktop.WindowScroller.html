StepFraction

The part of a page that Next() and Previous() scroll, greater than 0 and at most 1. The default 1.0 scrolls a full page as before; a scrolling capture uses e.g. 0.5 so consecutive frames overlap.

  • AbsoluteWindowMessage: the position moves by max(1, PageSize * StepFraction), clamped to the range.
  • WindowsMessage: below 1.0, SB_LINEDOWN / SB_LINEUP is sent until the position moved by max(1, PageSize * StepFraction) scroll units (checked after every message, at most CalculateLineSteps(uint, double) messages); 1.0 sends SB_PAGEDOWN / SB_PAGEUP.
  • MouseWheel: the wheel moves by WheelDelta (a page) times the fraction, see ScaleWheelDelta(int, double, bool).
  • KeyboardPageUpDown: the fraction is ignored, a key press always scrolls a page.
public double StepFraction { get; set; }

Property Value

UseFractionalWheelDelta

When false (the default) a partial-page wheel movement is rounded to whole notches (multiples of 120, at least one notch), as classic Win32 controls ignore or accumulate smaller deltas. Set this to true for applications which handle high-resolution wheel deltas (e.g. browsers), to scroll exactly StepFraction of WheelDelta.

WheelLocation

Where the mouse wheel input goes in MouseWheel, in screen coordinates. Null (the default) uses the middle of the ScrollingWindow. Set this to a point inside the area which should scroll, e.g. the page of a browser or the list of a dialog, when that is not in the middle of the window.
