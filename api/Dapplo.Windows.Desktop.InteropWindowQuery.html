GetTopWindows(IInteropWindow)

Get the windows in Z-order, from top (front) to bottom (back), without any filter. This is a snapshot, taken at once when this method is called (it's not lazy): without a parent (or with the desktop window as parent) EnumWindows is used, with a parent EnumChildWindows, filtered to the direct children (GetAncestor with GA_PARENT is the parent). Windows builds the list when the enumeration starts, so unlike a GetWindow(GW_HWNDNEXT) walk the result can't loop, skip or repeat windows when the Z-order changes. The windows can still change or be destroyed after the snapshot was taken, use Exists(IInteropWindow) when that matters. Note: the EnumWindows documentation states that Windows 8 and later only enumerate the top-level windows of desktop apps, so windows of Windows 8 style immersive apps might be missing.

GetVisibleApplicationWindows(bool)

Get the windows the user sees as application windows (see IsVisibleApplicationWindow(IInteropWindow, bool)), from top to bottom: visible, not minimized, with a title and a size, no tool window and no child window. The windows are a snapshot taken by GetTopWindows(IInteropWindow) when this method is called, the filter is applied lazily while enumerating the result.

IsVisibleApplicationWindow(IInteropWindow, bool)

Check if the window is what the user sees as an application window (e.g. what Alt+Tab shows): a top-level window (it can be owned, it has no parent) with a size, which is not a tool window (WS_EX_TOOLWINDOW), is rendered normally, is not a background Windows 10 app, is visible (WS_VISIBLE), has a title and is not minimized. This method will retrieve all information, and fill it to the interopWindow, it needs to make the decision.

IsVisiblePopup(IInteropWindow, bool)

Is the specified window a visible popup: a top-level window (it can be owned, it has no parent) with the WS_POPUP style, which has a size, is rendered normally, is visible (WS_VISIBLE) and is not minimized. Unlike IsVisibleApplicationWindow(IInteropWindow, bool) tool windows and windows without a title are included.
