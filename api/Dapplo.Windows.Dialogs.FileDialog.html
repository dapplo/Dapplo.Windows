Class FileDialog

Namespace
Dapplo.Windows.Dialogs

Dapplo.Windows.Dialogs.dll

Provides one-line convenience wrappers around the Windows Common Item Dialog for the most common scenarios. Returns null on cancellation; throws on unexpected errors.

Remarks

For more control (custom sidebar places, multi-select, suggested filenames, etc.) use the builder classes directly: FileOpenDialogBuilder, FileSaveDialogBuilder, or FolderPickerBuilder. See README.md for full documentation and error-handling guidance.

PickFileToOpen(nint, string, string, (string Name, string Pattern)[], string)

Presents a modern open-file dialog and returns the selected file path, or null if the user cancelled.

public static string PickFileToOpen(nint ownerHandle = 0, string title = null, string initialDirectory = null, (string Name, string Pattern)[] filters = null, string defaultExtension = null)

Parameters

ownerHandle nint

Handle of the owner window (Zero for top-level).

title string

Title bar text; null uses the Windows default ("Open").

initialDirectory string

Folder shown on open; null reuses the last-visited folder.

filters (string Name, string Pattern)[]

File-type filters, e.g. new[] { ("Images", ".png;.jpg"), ("All files", ".") }.

defaultExtension string

Extension appended when the user omits one (no leading dot, e.g. "txt").

Returns

string

Exceptions

COMException

Unexpected COM failure.

PlatformNotSupportedException

Called on a non-Windows platform.

InvalidOperationException

Called from a thread which is not an STA thread (e.g. a thread pool thread).
