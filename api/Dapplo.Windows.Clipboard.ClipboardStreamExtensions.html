Class ClipboardStreamExtensions

Namespace
Dapplo.Windows.Clipboard
Assembly
Dapplo.Windows.Clipboard.dll

These are extensions to work with the clipboard. The streams returned by GetAsStream and TryGetAsStream contain a copy of the clipboard content (the complete clipboard memory allocation, which can be larger than the actual data). This costs memory for the size of the content, but the stream can't outlive the clipboard lock and stays valid after the access token is disposed.
