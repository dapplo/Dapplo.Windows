Class WicMetadataPaths

Namespace
Dapplo.Windows.Imaging
Assembly
Dapplo.Windows.Imaging.dll

The metadata query paths per container: the same EXIF tag has a different path in each container, e.g. Software is "/app1/ifd/{ushort=305}" in a JPEG and "/ifd/{ushort=305}" in a TIFF or JPEG XR. Every method returns null when the container has no such path (or it isn't known to work). See doc/articles/imaging.md for which paths the codecs of Windows accept.

PngText(string, int)

The path of a PNG tEXt chunk with the keyword, e.g. "/tEXt/{str=Software}"; keywords like Title, Author, Description, Copyright, Creation Time, Software, Source and Comment are registered. Every tEXt chunk has one keyword, a second keyword in the same chunk replaces the first: give each keyword its own chunk index, e.g. "/[1]tEXt/{str=Description}".
