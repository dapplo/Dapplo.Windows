Represents the GRPICONDIR structure used in resource files. This is similar to ICONDIR but used for icon resources in PE files. See The format of icon resources

IconInfo

See ICONINFO structure Contains information about an icon or a cursor.

When filled by GetIconInfo, the two bitmaps (mask and color) are created for the caller, who must delete them exactly once. The properties BitmaskBitmap and ColorBitmap only expose the raw, non-owning, handles. Use TakeBitmaps(out SafeHBitmapHandle, out SafeHBitmapHandle) to transfer the ownership into SafeHandles, or DeleteBitmaps() to delete them. As this is a struct, copies share the same handles: only take or delete the bitmaps on one copy. When used for CreateIconIndirect, the bitmaps stay owned by the caller (the system copies them).

IconInfoEx

See ICONINFOEX structure Contains information about an icon or a cursor.

GetIconInfoEx creates two bitmaps (mask and color) which the caller owns and must delete exactly once. The properties BitmaskBitmap and ColorBitmap only expose the raw, non-owning, handles. Use TakeBitmaps(out SafeHBitmapHandle, out SafeHBitmapHandle) to transfer the ownership into SafeHandles, or DeleteBitmaps() to delete them. As this is a struct, copies share the same handles: only take or delete the bitmaps on one copy.
